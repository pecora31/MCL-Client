# Settings

## Appearance

* **Color palette**, six options: amber, indigo, emerald, rose, cyan, slate.
* **Window resolution**, 1280x720, 1440x900 (marked recommended), 1600x900, or 1920x1080.
* **Reduce motion**, turns off animated transitions for lower end machines.
* **Language**, English, Vietnamese, Chinese, Japanese, Korean, German, French, or Spanish.

## Performance

* **Default min and max RAM**, used as the starting point whenever a new profile is created. Default max RAM is 4096 MB, capped by what your computer actually has.
* **Default JVM arguments**, applied to new profiles alongside MCL's own built in optimization flags.
* **Auto Download Java**, lets MCL fetch the Java version a profile needs when nothing installed is new enough, instead of asking you to install one yourself.

## Behavior

* **Launch behavior**, what the launcher window does once the game starts: stay open, minimize, or hide until the game closes.
* **Discord Rich Presence**, shows what you are playing on your Discord profile.
* **Auto update**, checks for and installs new versions of MCL itself automatically.
* **Share My Skin**, see [Skin Studio](skin-studio.md) for what this controls.

## Storage

See [Storage Cleanup](storage-cleanup.md) for the dedicated cleanup tool, reachable from Settings.
