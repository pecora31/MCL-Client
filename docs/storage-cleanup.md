# Storage Cleanup

Reachable from Settings, this tool scans four categories and shows how much space each one would free up before you delete anything:

* **Unused game versions**, Minecraft versions downloaded for a profile that no longer exists or no longer uses them.
* **Orphaned instance folders**, leftover profile folders no longer tracked by MCL.
* **Unused Java runtimes**, Java versions MCL downloaded automatically that nothing currently needs, including any left partially unpacked from an interrupted download.
* **Temporary cache**, logs and other short lived files.

Each category has its own checkbox, so you can clean only what you are comfortable with. After cleanup, press rescan to confirm the space was actually freed.
