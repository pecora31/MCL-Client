# Home

MCL Client is a custom Minecraft launcher built with Tauri 2 (Rust) and React 19. It is designed for friend groups and private servers, with automatic mod loader installation, teammate skin syncing, and self hosted servers, all without an account or any analytics.

## Where to start

**Setup**

- [Getting Started](getting-started.md): installing the launcher, or setting up a development build
- [Creating a Profile](creating-a-profile.md): mod loaders, versions, RAM, and Java

**Playing**

- [Mod Manager](mod-manager.md): browsing Modrinth and CurseForge, installing modpacks, conflict warnings
- [Skin Studio](skin-studio.md): the 3D skin preview and how teammates see your skin in game
- [Server Hub and Server Config](server-hub-and-server-config.md): saving servers, pinging them, and editing an existing server's settings
- [Sharing Profiles](sharing-profiles.md): sending a modpack setup to a friend with a share code

**Hosting a server**

- [Hosting a Server Locally](hosting-a-server-locally.md): running a server on your own computer and joining it yourself
- [MCL Agent: Remote Hosting](mcl-agent-remote-hosting.md): managing a server on a VPS from the same tab, with certificate pinned HTTPS instead of SSH

**Reference**

- [Settings](settings.md): every option in the Settings tab
- [Storage Cleanup](storage-cleanup.md): reclaiming disk space
- [Troubleshooting and FAQ](troubleshooting-and-faq.md): common errors and what causes them
