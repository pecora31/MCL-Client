# Trang Chủ

MCL Client là một launcher Minecraft tuỳ chỉnh, được xây dựng bằng Tauri 2 (Rust) và React 19. Launcher này dành cho nhóm bạn bè và server riêng, tự động cài mod loader, đồng bộ skin giữa các người chơi, và tự host server, tất cả đều không cần tài khoản hay theo dõi dữ liệu người dùng.

## Bắt đầu từ đâu

**Cài đặt ban đầu**

- [Bắt Đầu](getting-started.md): cài launcher, hoặc dựng môi trường phát triển
- [Tạo Profile](creating-a-profile.md): chọn mod loader, phiên bản, RAM và Java

**Chơi game**

- [Quản Lý Mod](mod-manager.md): duyệt Modrinth và CurseForge, cài modpack, cảnh báo xung đột
- [Skin Studio](skin-studio.md): xem trước skin 3D và cách đồng đội thấy skin của bạn trong game
- [Quản Lý Server và Cấu Hình](server-hub-and-server-config.md): lưu server, ping server, chỉnh sửa cấu hình một server đã có sẵn
- [Chia Sẻ Profile](sharing-profiles.md): gửi cấu hình modpack cho bạn bè bằng mã chia sẻ

**Tự host server**

- [Host Trên Máy Của Bạn](hosting-a-server-locally.md): chạy server ngay trên máy tính của bạn và tự vào chơi
- [MCL Agent: Host Từ Xa](mcl-agent-remote-hosting.md): quản lý server trên VPS ngay trong cùng một tab, kết nối HTTPS có ghim chứng chỉ thay vì dùng SSH

**Tài liệu tham khảo**

- [Cài Đặt](settings.md): toàn bộ tuỳ chọn trong tab Cài Đặt
- [Dọn Dẹp Bộ Nhớ](storage-cleanup.md): giải phóng dung lượng ổ đĩa
- [Khắc Phục Sự Cố và FAQ](troubleshooting-and-faq.md): các lỗi thường gặp và nguyên nhân
